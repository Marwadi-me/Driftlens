The Problem

Code Moves Fast — Documentation Silently Lags Behind

⚠️ Renamed CLI Flags

A CLI flag is renamed (--timeout → --deadline), but user guides and tutorials continue explaining the obsolete flag name.

⚠️ Changed Default Configurations

A socket timeout changes from 30s to 60s in source code, but configuration tables and architecture docs still state 30s.

⚠️ Modified API Signatures

Function signatures change (registerUser(email, password, tenantId)), yet public API tutorials describe the legacy parameters.

⚠️ Deleted Features & Routes

An endpoint (/api/v1/legacy-export) is removed from code, but remains documented as available in README files.

Architecture

The 6-Stage DriftLens Pipeline

1. Git Diff Parser

Extracts unified git diffs across base...head, classifying source code, docs, and configs with shallow-clone resilience.

2. Entity Extractor

Statically extracts changed CLI flags, constants, defaults, and API routes from changed hunks.

3. Sentence Chunking

Deconstructs Markdown into sentence-level units with exact line ranges, sections, and table rows.

4. Candidate Matcher

Multi-signal scoring: exact identifier (+45%), old value (+30%), section (+15%), file correlation (+15%).

5. Same-PR Shield

Detects if the documentation was already updated in the same PR and suppresses false warnings.

6. Qwen 2.5 7B AI

Evaluates semantic contradiction over bounded evidence with calibrated composite confidence.

Confidence Formula & Zero False Alarms

Mathematical Confidence Calibration

Calibrated Formula

Confidence = 0.35 × DetScore + 0.25 × CandScore + 0.40 × LLMScore
  • Deterministic Score (35%): 1.0 for hard AST shifts (renamed flags, constants); 0.80 for general changes.
  • Candidate Overlap (25%): Exact identifier match, old value mention, section relevance.
  • LLM Reasoning (40%): Open-weight Qwen 2.5 7B semantic contradiction score.
  • Threshold Filter: Scores below 60% are discarded to eliminate false alarms.

Actionable Severity Tiers

  • 🔴 HIGH SEVERITY: Direct factual contradiction (renamed flag, altered default). Blocks merge with Exit Code 1.
  • 🟡 MEDIUM SEVERITY: Behavioral nuance or indirect parameter shift.
  • ⚪ LOW SEVERITY: Minor reference drift.
  • 🛡️ Same-PR Suppression: If the developer already corrected the documentation in the same commit, DriftLens suppresses the warning.
